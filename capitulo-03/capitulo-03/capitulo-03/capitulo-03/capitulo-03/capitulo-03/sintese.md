# Síntese do Capítulo 3 – Estruturas de Controle

O Capítulo 3 apresenta as estruturas de controle utilizadas na programação. Essas estruturas permitem organizar a execução de um algoritmo e fazer com que o programa execute diferentes ações de acordo com as situações.

## Estrutura de Sequenciação

Na estrutura de sequenciação, os comandos são executados em uma ordem, um depois do outro.

Um exemplo é o cálculo da área de um círculo. Primeiro o programa recebe o valor do raio, depois realiza o cálculo e, por fim, apresenta o resultado.

Essa estrutura é importante para entender a sequência de execução de um programa.

## Estrutura de Seleção

A estrutura de seleção permite que o programa tome decisões de acordo com uma condição.

Em Python, podemos utilizar comandos como `if`, `elif` e `else`.

O `if` verifica uma condição. O `elif` permite verificar outra condição caso a anterior não seja verdadeira. O `else` é executado quando nenhuma das condições anteriores é atendida.

Essa estrutura permite que o programa tenha comportamentos diferentes dependendo dos valores informados pelo usuário.

## Estrutura de Repetição

A estrutura de repetição permite executar um determinado trecho do programa várias vezes.

No capítulo, trabalhamos com situações em que é necessário repetir ações. Em Python, podemos utilizar estruturas como `for` e `while`.

O `for` pode ser utilizado quando sabemos quantas vezes queremos repetir uma ação. Já o `while` continua repetindo enquanto uma determinada condição for verdadeira.

## O que aprendi no capítulo

Neste capítulo, aprendi como utilizar estruturas de controle para organizar melhor os programas. Entendi que a estrutura sequencial executa os comandos em ordem, a estrutura de seleção permite tomar decisões e a estrutura de repetição permite executar comandos várias vezes.

Também comecei a entender melhor como `if`, `elif`, `else`, `for` e `while` funcionam na prática. Esses conceitos foram utilizados nos exercícios que desenvolvi em Python durante o capítulo.
